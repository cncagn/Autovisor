# 每日累计学习

新版默认每个账号记录、每门课程每天累计播放 30 分钟，日期按北京时间划分。需要每天自行启动程序；不会创建自动启动任务。

在 `config.ini` 的 `[course-option]` 使用：

```ini
limitMaxTime = 0
dailyLimitMinutes = 30
studyProfile = account1
reviewCompletedCourses = False
```

- `dailyLimitMinutes` 是跨启动累计的每日额度。今天已经播放 12 分钟，再次打开只剩 18 分钟；用完后当天不再播放，次日重新获得额度。设为 `0` 关闭每日累计功能，保留旧的单次计时方式。
- `limitMaxTime` 仍是每次启动的课程运行时限。每日模式建议设为 `0`，由每日实际播放额度控制停止。
- `studyProfile` 是同一账号固定使用的记录别名，不是账号密码。默认 `account1`。换账号请更换别名或使用独立发行目录。配置别名优先，保证登录 Cookie 刷新不会改变计时身份；留空时尝试从智慧树 `CASLOGC` 中读取稳定的用户 ID，无法识别则停止并要求填写别名。别名/用户 ID 经过哈希后写入记录，不保存密码或认证 Token。
- `reviewCompletedCourses = False` 会在平台目录显示全部视频完成时停止。只有设为 `True` 才进入复习；复习同样消耗每日额度。
- 旧配置缺少 `dailyLimitMinutes` 时每日累计默认关闭；请添加上述配置启用。空课程链接不再打印错误提示。

程序启动课程时显示当天已学、剩余和历史累计分钟数。查看所有日期记录可运行：

```powershell
.\Autovisor.exe --study-history
```

这个命令不打开浏览器、不检查更新，也不需要账号密码。便携包可双击 `查看学习记录.cmd`。

记录位于程序旁的 `data/study-history.sqlite3`。升级或移动软件时请保留整个 `data` 目录；它还可能包含自己的登录 Cookie，不要分享给其他人。记录从新版首次计时开始，不根据旧日志推测或补填学习时长。

计时约每 0.5 秒采样一次播放器。只有视频正常推进、播放开关开启、无可见阻挡弹窗且未暂停/缓冲/拖动时累计真实经过的秒数；倍速播放不会把一分钟当作数分钟。识别到跳转、视频切换、系统休眠或异常时钟跳变的间隔不累计。跨午夜的正常样本按两天拆分。每个有效样本通过 SQLite 事务立即保存；强制关闭可能丢失最后一个尚未采样的短间隔，正常任务结束也有同样的采样精度限制。

同一记录文件的并发写入不会覆盖之前时长，累计不会超过配置额度。存储损坏或写入失败会停止本轮并保留原文件，不会静默重置额度。多个账号建议使用独立目录。

这里统计的是本地播放器运行时长。课程学习进度、平台认定的有效学习和习惯分仍以课程成绩页为准；视频全部完成不等同于完成平时测试或期末考试。

源码打包可使用新目录，避免覆盖旧配置：

```powershell
.\.venv\Scripts\python.exe build.py --dist-dir dist/daily-3.18.5
```
